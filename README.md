# 📝 Client-Side Blog CMS

A simple client-side Blog Content Management System that allows users to create, edit, delete, preview, and filter blog posts directly in the browser.

## ✨ Features

- 📝 Create blog posts
- ✏️ Edit existing posts
- 🗑️ Delete posts with confirmation
- 👁️ Preview posts
- 📌 Draft and Published status
- 🔍 Filter posts by status
- 💾 Store posts using LocalStorage
- 📅 Display post creation date
- 🔄 Data remains available after page refresh
- 📱 Responsive design
- 🛡️ Basic HTML escaping for post content

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- LocalStorage
- Browser APIs
